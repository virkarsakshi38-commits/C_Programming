# Logic Building Assignment No 12

## Programs

1. **Reverse Digits:** Displays the digits of a number in reverse order.
2. **Check Zero:** Checks whether a number contains zero or not.
3. **Frequency of 2:** Counts how many times digit 2 appears.
4. **Frequency of 4:** Counts how many times digit 4 appears.
5. **Count Digits Less Than 6:** Counts digits that are smaller than 6.

## Concepts Used
- While Loop
- If-Else
- Modulus Operator
- Arithmetic Operations
- Functions
