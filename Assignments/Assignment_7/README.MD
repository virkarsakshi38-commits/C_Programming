# Assignment 7

This assignment contains 5 C programs based on loops and number patterns.

## Programs
1. Print `$ *` pattern N times.
2. Print numbers from 1 to N.
3. Print numbers from -N to N.
4. Print all odd numbers up to N.
5. Print the first 5 multiples of N.

## Concepts Used
- Loops
- Conditional Statements
- Arithmetic Operators
- Logic Building
