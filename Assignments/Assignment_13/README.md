# Logic Building Assignment No 13

## Programs

1. **Count Even Digits:** Counts all even digits in a number.
2. **Count Odd Digits:** Counts all odd digits in a number.
3. **Count Digits Between 3 and 7:** Counts digits greater than 3 and less than 7.
4. **Multiplication of Digits:** Calculates the multiplication of all digits.
5. **Difference of Digit Sums:** Calculates the difference between the sum of even digits and odd digits.

## Concepts Used
- While Loop
- If-Else
- Modulus Operator
- Arithmetic Operations
- Functions
