# Logic Building Assignment No 14

## Programs

1. **Multiplication of Factors:** Calculates the multiplication of all factors.
2. **Factors in Decreasing Order:** Displays all factors in descending order.
3. **Non-Factors:** Displays all numbers that are not factors.
4. **Sum of Non-Factors:** Calculates the sum of all non-factors.
5. **Difference of Factors and Non-Factors:** Calculates the difference between the sum of factors and non-factors.

## Concepts Used
- For Loop
- If-Else
- Modulus Operator
- Arithmetic Operations
- Functions
