
# Logic Building Assignment 9

## Programs

1. **Star and Hash Pattern:** Prints `*` and `#` symbols.
2. **Currency Conversion:** Converts US dollars into Indian rupees (1 USD = ₹70).
3. **Even Factorial:** Calculates the product of even numbers.
4. **Odd Factorial:** Calculates the product of odd numbers.
5. **Factorial Difference:** Calculates the difference between even and odd factorials.
