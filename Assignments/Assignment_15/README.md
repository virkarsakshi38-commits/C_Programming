# Logic Building Assignment No 15

## Programs

1. **Print Name:** Accepts and displays the user's name.
2. **Greater Than 100:** Checks whether a number is greater than 100 or not.
3. **Check Equality:** Checks whether two numbers are equal or not.
4. **Multiplication:** Accepts three numbers and displays their multiplication.
5. **Percentage:** Calculates percentage using total and obtained marks.

## Concepts Used
- Variables
- If-Else
- Arithmetic Operations
- Functions
- Input and Output
